# Al-Muhasib Mobile POS 📱💼

[![React Native](https://img.shields.io/badge/Framework-React%20Native-61DAFB?logo=react&logoColor=black)](https://reactnative.dev)
[![TypeScript](https://img.shields.io/badge/Language-TypeScript-3178C6?logo=typescript&logoColor=white)](https://www.typescriptlang.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

An offline-first Mobile Point of Sale (POS), Invoicing, and Inventory Management application for Android and iOS devices.

---

## ✨ Key Features

- **🧾 Mobile Invoicing:** Generate and share digital invoices (PDF/Image) via WhatsApp or Bluetooth thermal printers.
- **📦 Pocket Inventory:** Track product stock levels, categories, barcodes, and profit margins on the go.
- **👥 Customer & Supplier Ledger:** Record customer balances, credit sales, and vendor invoices.
- **📊 Real-Time Financial Reports:** Daily revenue breakdown, gross margin calculations, and expense logs.
- **📴 100% Offline Capability:** Operates smoothly without internet connectivity.

---

## 🚀 Getting Started

```bash
git clone https://github.com/monestw-cell/al-muhasib-mobile.git
cd al-muhasib-mobile
npm install
npm run android
```
