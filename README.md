# المحاسب الحنيوك - نظام المحاسبة ونقطة البيع للجوال (Offline-First Mobile POS & Accounting)

تطبيق جوال متكامل وخفيف يعمل بالكامل دون الحاجة للاتصال بالإنترنت (Offline-First)، مصمم خصيصاً للمحلات ومتاجر التجزئة والبقالات باللغة العربية مع واجهة مستخدم عصرية وأنيقة تدعم الوضعين الفاتح والداكن (Light & Dark Themes).

---

## 🌟 المميزات الرئيسية (Core Features)

1. **نقطة بيع سريعة (Fast POS Workflow):**
   - دعم البحث باسم المنتج أو الباركود.
   - دعم قارئ الباركود الخارجي (Bluetooth / USB) كإدخال لوحة مفاتيح فوري.
   - تصفية المنتجات حسب تصنيفات السلع.
   - سلة شراء تفاعلية بسحب سفلي (Bottom Sheet).
   - خيارات متعددة للدفع: **نقدي (Cash)**، **شبكة/بطاقة (Card)**، **آجل (Credit)**.
   - حساب الفكة المتبقية للعميل آلياً.
   - إمكانية تعليق واسترجاع الفواتير (Hold/Resume Sales).

2. **إيصال حراري 80mm وررمز QR المحلي:**
   - تصميم إيصال حراري مميز بأسلوب الورق الحراري وشعار المحاسب الحنيوك.
   - توليد وتضمين رمز QR محلياً لملخص الفاتورة.
   - خيارات الطباعة المباشرة، المشاركة عبر واتساب/إيميل، أو الحفظ كملف PDF.

3. **إدارة المنتجات والمخزون:**
   - إضافة وتعديل وحذف المنتجات وتوليد الباركود تلقائياً.
   - التتبع التلقائي لحركات الدخول والخروج والتسويات اليدوية.
   - تنبيهات المنتجات قريبة النفاد (Low Stock Alerts).
   - تقييم إجمالي سعر التكلفة وسعر البيع للمخزون.

4. **إدارة ديون العملاء والموردين:**
   - سجل شامل لذمم العملاء ومتابعة سقف الائتمان.
   - تسديد الديون وتوثيق السندات آلياً.
   - سجل فواتير وحسابات الموردين.

5. **إدارة الصندوق والورديات:**
   - فتح وإغلاق وردية الكاشير وحساب العجز أو الزيادة.
   - تسجيل حركات الإيداع والسحب النقدي من الدرج.

6. **إدارة المصاريف والتقارير:**
   - تسجيل مصاريف التشغيل والمستلزمات.
   - تقارير المبيعات والأرباح اليومية.
   - تصدير التقارير بصيغة CSV / Excel بدعم اللغة العربية (UTF-8 BOM).

7. **الأمان والنسخ الاحتياطي المحلي:**
   - نظام صلاحيات وأدوار: (مدير، كاشير، محاسب، مسؤول مخزون، مشرف).
   - تشفير وحفظ كلمة المرور وساعات الجلسات محلياً.
   - إنشاء نسخة احتياطية من قاعدة البيانات SQLite ومشاركتها واستعادتها بضغطة زر.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الاطار الرئيسي:** Expo (React Native + TypeScript)
- **قاعدة البيانات المحلية:** `expo-sqlite`
- **التخزين الآمن:** `expo-secure-store`
- **إدارة الحالة:** `Zustand`
- **الطباعة والمشاركة:** `expo-print` & `expo-sharing`
- **توليد رمز QR:** `react-native-qrcode-svg`
- **التصميم:** Vanilla React Native StyleSheet مع تطبيق ثيم Stitch (فاتح وداكن) وبدعم RTL كامل.

## 🚀 طريقة التشغيل والتطوير (How to Run)

### 1. تثبيت الحزم (Install Dependencies)
```bash
npm install
```

### 2. تشغيل السيرفر المحلي (Start Expo App)
```bash
npm run start
```

### 3. تشغيل على الأندرويد (Run Android)
```bash
npm run android
```

---

## 📦 طريقة بناء ملف APK / AAB للأندرويد

لبناء حزمة APK تجريبية أو AAB للنشر على متجر Google Play:

```bash
# استخدام Expo Application Services (EAS Build)
npx eas build -p android --profile preview
```
أو البناء المحلي في بيئة Android Studio:
```bash
npx expo run:android --variant release
```
